# strm 管理：网格视图 + 默认看全部任务

## 起因

2026-11-12 用户两句话：

- 「strm 管理 页面现在是列表展示，再加一个 网格视图展示，你看看如何设计好看」
- 「还有现在是默认展示第一个任务的，改成默认展示全部吧」

现状（动手前读的代码）：

- `/strm` 一进来没带 `taskId` 就 `replace` 到任务表里第一个任务；页面上所有东西（列目录、搜索、媒体信息、删除、六个弹框）都只认一个 `b.taskId`。
- 内容只有一种画法：md 以上是表格（名称 / 类型 / 大小 / 修改时间 / 操作），md 以下一条一张卡。
- 海报只在背景里：`useDirPosters` 给墙要当前目录前 24 个子目录的图（联网），其余子目录每 48 个一批离线数「认出来几个」；本地图走 `lib/poster-images.ts` 取成 blob（带令牌），同时最多取 2 张、缓存 80 张 / 32 MB、墙上的钉住。
- 收藏夹已经有一面前景海报墙（`LibraryWorks.tsx`：2:3 海报 + 两行字、悬停一圈品牌色、角标压在 `bg-background/85` 上），strm 页的网格要和它是一家。

## 方案

### 一、设计上的取舍

这一页管的是「本地 strm 目录」，目录的那几层（库 → 作品 → 季）天然是海报，文件那一层（集、nfo、字幕）天然是编号和扩展名。网格视图就按这个分成两种格子，不做「所有东西都是一样大的图标格」：

```
[任务 ▾ 全部任务] [筛选…                       ] [搜索] [☰|▦]
全部任务 › tv › 辐射 (2024) [tmdbid=106379]              ☐ 全选

片架（目录）：2:3 海报，直接摆在画布上，没有卡片外框
┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐
│海报│ │海报│ │ S01│ │ 📁 │ │海报│ │海报│ │海报│      没海报的：季目录写季号，别的画文件夹
└────┘ └────┘ └────┘ └────┘ └────┘ └────┘ └────┘
辐射     最后生还者 Season 01 extras  …
2024     2023

文件页（文件）：一块半透明面板，里面是没有边框的格子
┌──────────────────────────────────────────────────────────┐
│ ┌───┐ 辐射 - S02E01.strm      ┌───┐ 辐射 - S02E02.strm   │
│ │S02│ 4K HEVC DV DDP 5.1 +2   │S02│ 4K HEVC DV …         │
│ │E01│ 312 B · 2026/11/6 10:22 │E02│ 312 B · …            │
│ └───┘                         └───┘                      │
│ ┌───┐ tvshow.nfo                                         │
│ │NFO│ 2.1 KB · …                                         │
│ └───┘                                                    │
└──────────────────────────────────────────────────────────┘
```

- **片架**：目录一格一张 2:3 海报，下面两行字（去掉 id 标签和年份的名字 / 年份）。画法照收藏夹：`rounded-lg`、悬停和选中一圈 `ring-brand`，不加阴影、不放大。列数按容器宽度自己排（`minmax(8.5rem, 1fr)`，1440 宽大约 7 列），手机固定 3 列。
- **没有海报的目录**不画成灰盒子里再写一遍名字（名字已经在下面了）：季目录用等宽字写季号 `S01` / `SP`，别的画一枚文件夹。进到作品里面（路径里有 id 标签）时，没有自己的图的子目录借作品那张**压淡了当底**（30%），季号 / 文件夹照样写在正中——一排季目录不会看成一排一模一样的海报；季目录自己有图的才整张显示，季号缩成左下角一枚小标。
- **文件页**：文件是「印章 + 名字 + 旗标 + 大小时间」的横格。印章是这一格的视觉重心：strm 写集号（`S02` 小、`E05` 大，品牌色淡底），认不出集号的 strm 画胶片；附件写扩展名（`NFO` / `ASS`），残留分段用警告色。一季 24 集排成三四列，缺哪一集一眼看得出来。格子本身没有边框，整块放在一张 `bg-card/60 + backdrop-blur-sm` 的面板上——和列表那张表格同一种面板，只有一层毛玻璃（几百个格子各自毛玻璃太贵）。**strm 排在前面、附件另起一块**（中间一条分隔线）：按名字混排的话每集后面夹着它的 nfo / 字幕，集号连不成一串。strm 只有几百字节，格子里只写时间不写大小。
- **勾选和菜单**平时收着：指针悬停、键盘聚焦、或者已经有勾选的时候才出现；触屏（`pointer-coarse`）上一直在。海报上的两个角（左上勾选、右上「⋯」）压在 `bg-background/90` 上；文件格的勾选压在印章左上角，触屏上改成排在印章左边。整格可点：目录进去，strm 开详情抽屉。
- **动效**只有两处：海报解出来以后淡入（300 ms，`motion-reduce` 关掉）、悬停的那一圈。不做入场动画。
- 视图开关是工具栏右端的两格图标（列表 / 网格），画法照收藏夹的页签；选了哪个记在 `localStorage`（`openstrm.strm.view`），**没选过的是网格**（用户看过成品后定的，见末节；一开始留的是列表）。

### 二、全部任务

- 地址里没有 `taskId`、任务又不止一个：就是「全部任务」，不再跳到第一个任务。任务下拉最上面多一项「全部任务」。**只有一个任务时照旧直接进那个任务**（「全部」就是它，工具菜单也不用多点一下）。
- 内容是每个任务根目录那一层，**按任务分组**：一组一个标题行（账户徽章 + 网盘目录 + `→ 本地目录`，和任务页那一行同一种写法；右边是条数和「打开」），可以折叠。不拍平成一个大列表：这一页的每个操作都是按任务做的，同一部作品在两个任务里各有一份时拍平了分不清谁是谁。
- 共用同一个本地目录的几个任务只列一组（算第一个任务的；后端的体检 / 校验 / 修正本来就按内容前缀跳过兄弟任务的文件）。任务根嵌在另一个任务根里面的，外面那个任务的列表里不再重复列这个目录。
- 筛选框筛所有组；回车搜索把每个任务各搜一遍合起来，结果里「所在目录」带上任务的本地目录。
- 行上的操作（进目录、查看、校验、重新生成、修正、复制、归档、删除）都按**这一行自己的任务**来；进目录就换到那个任务的地址（`?taskId=…&path=…`），面包屑最前面多一级「全部任务」可以回来。
- 页头的「工具」菜单是对「当前目录」做的，全部任务下没有当前目录：灰掉，悬停说明先选一个任务。
- 背景墙：全部任务 + 列表视图用任务页那面全库的墙（`useAllPosters`）。

### 三、海报从哪来、怎么取

网格里每个目录要一张图，目录可能上千个，不能像背景那样一口气要：

- **进了视口附近才问**：全页共用一个 `IntersectionObserver`（上下各多看 600px），格子进来了才把自己排进队列；队列按任务凑批（一批最多 48 个，最近进来的先问），一次只发一批。
- **先离线、再联网**：第一遍 `offline: true`，本地图 / 详情缓存 / 整理记录有的立刻上墙；回包里的 `pending`（有 id、离线没问到答案、配了 TMDB key）再 12 个一批联网补。任何一批回 `unreachable`（TMDB 连不上）就不再问，直到刷新或换目录。
- **图片**也是进了视口附近才取，离开就解钉：外链直接给 `<img>`；本地图走 `poster-images.ts` 的 blob。那边的并发上限从「每批 2 张」改成**全局 2 张**（背景墙和网格共用），排队的工夫格子滚走了就不取了。
- 网格要图带 `compact: true`：本地图超过 512 KB、离线又有外链小图的，换成小图、本地那张留作后备（任务页那面墙的规矩，后端现成的）。一屏二十几张刮削器存的原图太重。
- 网格视图下背景墙：漂移的那面（`stream`）不画——前景已经是一面墙了，`useDirPosters` 这时只数「认出来几个」、不下图、第一批也改成离线；进到作品里的单张糊图（`single`）照旧。

### 四、后端（只动海报接口）

`POST /api/strm/posters`：

- 入参多 `compact`（默认 false）：按 `WALL_LIMITS.LOCAL_MAX_BYTES` 换小图。
- 回包多 `pending: string[]`（值得联网问的目录；没配 key 是空的；这一次联网问过的不再算）和 `unreachable?: true`（这一次去 TMDB 连不上）。

别的接口不动。全部任务的列表和搜索由前端按任务各发一次（并发 4 / 3），不加聚合接口。

### 五、代码怎么摆

- `lib/strm-entries.ts`：`refKey`、`rootKey`、`distinctRoots`、`splitWorkName`、`seasonStamp`、`episodeStamp`、`extStamp`、`workRootOf`（纯函数，`lib/strm-entries.test.ts`）。
- `lib/poster-images.ts`：`holdPoster`（单张）+ 全局取图队列；`toBackdropPosters` 改成建在它上面。
- `hooks/use-near-viewport.ts`、`hooks/use-tile-posters.ts`（`useTilePosters` / `useHeldImage`）。
- `app/strm/use-strm-browser.ts`：行带 `taskId` 和 `key`；全部任务的列表 / 搜索 / 媒体信息 / 删除按任务分发。
- `app/strm/components/`：`entry-actions.tsx`（行操作的类型、`DirMenu` / `FileMenu`）、`GroupHeader.tsx`、`StrmList.tsx`（原来 page.tsx 里的表格和手机卡片搬过来）、`StrmGrid.tsx`、`ViewSwitch.tsx`、`DeleteStrmDialog.tsx`。
- `page.tsx` 只留状态、页头、工具栏、空状态和弹框。

### 不做

- 不加排序控件（名称 / 最近修改）：后端现在只按「目录在前、名字自然序」排，要排新旧得先决定按哪个时间（目录自己的修改时间不反映新集）。
- 图片附件、每集的剧照不取缩略图：印章只有 44px，为它拉几百 KB 到几 MB 的图不值。
- 分类目录（`电影/`、`动漫/`）不借下一层的海报拼封面：要后端往下走一层，另算一件事。
- 季目录不认 `season01-poster.jpg` 这种放在剧目录里的季海报（后端 `localPosterName` 只看目录自己里面）。
- 不记「上次看的任务」：用户要的是默认看全部。
- 分组标题不吸顶。

## 浏览器冒烟（2026-11-12）

**环境**：全新的 scratch 库（不是 `config/openstrm.db` 的拷贝），后端 `127.0.0.1:4100`（`BACKEND_HOST=127.0.0.1`，出站 HTTPS 指到连不上的代理），默认口令当场换成随机临时口令；一个连不上的 OpenList 账号（`http://127.0.0.1:9`）挂三个不带定时的任务 `movie` / `tv` / `big`。假片库在 scratchpad：照本机 `data/` 的目录名和文件名造的 `movie`（17 部）、`tv`（16 个目录，其中 4 个没有 id 标签）加一个 180 部的 `big`，strm 内容是假的；作品目录里三分之二放纯 Python 画的 `poster.png`，六分之一走详情缓存（海报地址指到本机 `127.0.0.1:4199` 的假图服务，顶替外链），其余没有图；一张 807 KB 的大图看 `compact`；三分之二的 strm 灌了探测结果。前端 `next dev -p 3223`。Chrome 窗口这次是可见的（1440 宽）。
